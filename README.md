# 识字加油站

小学语文二年级上册 · 单元五 · 语文园地五 配套识字资源。

通过一首自编的《识字小歌》，将 9 个易混淆的形声字词语串联成四句押韵小诗，配合手绘插画和朗读音频，帮助低龄儿童在情境中识字、辨字。

---

## 词语

山峰、密蜂、刀锋、爱慕、扫墓、开幕、吵闹、炒饭、抄写

## 识字小歌

> 山峰密蜂爱慕桃，
> 扫墓远离刀锋好。
> 开幕炒饭香满灶，
> 抄写认真莫吵闹。
